# models/

Place les fichiers exportés depuis le notebook Kaggle (section 15 / 17) ici :

- `netscope_model.pkl`     — le modèle entraîné (LightGBM ou équivalent)
- `netscope_features.pkl`  — la liste ordonnée des features attendues par le modèle

Ces fichiers ne sont pas générés en local — ils viennent de l'exécution du notebook
sur Kaggle (accès au dataset CIC-Bell-DNSExF2021), à télécharger depuis le panneau
"Output" de Kaggle puis à copier ici tels quels.
